# Birthday Archive — Print Edition

Отдельная печатная копия всех **10 реальных сцен** из `../prototype-3/scenes.js`.
Web-версия не изменена. Готовые файлы: `pdf/01.pdf` … `pdf/10.pdf`.
Каждый PDF: **1 страница, 210 × 125 мм**, без bleed и браузерных колонтитулов.
При печати выберите **Actual size / 100%**, отключите Fit to Page.

## Повторный экспорт

Нужен Node.js 20+:

```bash
cd prototype-3-print/export
npm ci
npx playwright install chromium
npm run export:pdf
```

Можно использовать установленный Chrome вместо скачанного Chromium:

```bash
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" npm run export:pdf
```

На macOS цветные эмодзи берутся из Apple Color Emoji. На другой системе
необходим установленный цветной emoji-шрифт; после смены платформы повторите
визуальную проверку. Roboto Mono находится в `fonts/`, сеть для страниц не нужна.

## Предпросмотр и проверка

Откройте `index.html?scene=1` … `index.html?scene=10` через локальный сервер:

```bash
cd prototype-3-print
python3 -m http.server 4173
```

Адрес: `http://localhost:4173/index.html?scene=3`.

После экспорта техническая проверка и рендер всех PDF:

```bash
python3 -m pip install pypdf Pillow
# Также нужен Poppler (pdftoppm), например: brew install poppler
python3 export/validate-pdf.py
```

В `export/qa/` создаются PNG каждого **реального PDF**, обзорный лист,
данные DOM и результаты проверки. Эта временная папка исключена из Git.
Техническая проверка не заменяет просмотр всех PNG.
Результаты текущего комплекта описаны в `PRINT_VALIDATION.md`.

## Устройство

- `content.js`, `engine.js`, `scenes.js` — точные копии web-исходников.
- `print-app.js` доводит исходный таймлайн до финального состояния в instant-mode,
  выключает звук и останавливает бесконечные эффекты.
- `styles.css` сохраняет исходную композицию, отключает мобильную перестройку
  и использует печатные оттенки. `print.css` убирает CRT, курсоры и glow,
  задаёт общий contain-масштаб и мягкий переход сверху портрета сцены 3.
- Все сцены: холст 1600 × 900, один масштаб 0.472441, итоговый холст
  200 × 112.5 мм, центр страницы, поля 5 мм по бокам и 6.25 мм сверху/снизу.
- Экспорт через Playwright; pdf-lib приводит MediaBox/CropBox/TrimBox к точным
  210 × 125 мм после округления Chromium. Содержимое не растягивается,
  не растрируется целиком и не получает дополнительного JPEG-сжатия.
- Фото неизменны. Только технические PNG карты Málaga имеют печатную палитру.
  `recolor-malaga.py` читает оригиналы из `../prototype-3/photos/`, поэтому
  повторный запуск не перекрашивает уже обработанные изображения.

Ограничение: исходные плотные сцены при таком размере содержат мелкий текст;
особенно календарь 04 и подписи карты 06. Содержание и композиция сохранены.
