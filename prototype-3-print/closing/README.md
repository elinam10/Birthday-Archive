# Closing documents — print only

Добавлены только две страницы к существующему набору:

- `../pdf/12.pdf` — FINAL ASSESSMENT.
- `../pdf/13.pdf` — CASE CLOSED.

Исходные 01–11.pdf и все прежние print/web-файлы не изменены. Страницы
используют существующие `../styles.css` и `../print.css` по ссылке;
`closing.css` задаёт только композицию этих двух новых документов.
HTML полностью статический: нет JS, фотографий, кнопок или навигации.

## Повторный экспорт только 12 и 13

При уже установленных зависимостях существующего `export/package.json`:

```bash
cd prototype-3-print
node closing/export.mjs
```

Для установленного Chrome на macOS:

```bash
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" node closing/export.mjs
```

Не запускайте общий экспорт ради этих страниц: отдельный скрипт пишет
только `12.pdf` и `13.pdf`. Старый pipeline намеренно не редактировался.
Диагностика новых страниц сохраняется в игнорируемую папку
`../export/qa/closing/`.

## Проверка готовых файлов

Проверены оба реальных PDF, каждый отрендерен Poppler при 96 dpi
(100% CSS-масштаб) и 192 dpi. Просмотрены обе страницы при 100%:

- Ровно одна страница в каждом PDF.
- MediaBox, CropBox, TrimBox: ровно 210 × 125 мм.
- Тот же Roboto Mono, все используемые PDF-шрифты встроены.
- Тексты сверены с извлечённым PDF-текстом: всё присутствует.
- Общий холст 1600 × 900; transform из print.css без изменений:
  translate(5mm, 6.25mm) scale(0.472441).
- Безопасные поля соблюдены; нет обрезанного текста.
- Те же CSS variables, рамка с угловыми метками, HUD, 1px линии,
  2px архивный штамп из обложки и фон #F1F3EC.
- Проверены отсутствие фильтров, теней, анимаций и controls;
  CRT-псевдоэлементы отключены общим print.css.
- FINAL ASSESSMENT: семь результатов проверки, итоговое разрешение,
  компактный APPROVED и четыре служебных поля.
- CASE CLOSED: свободное пространство, один основной заголовок,
  короткое завершение, даты и END OF FILE; без таблиц и dashboard.
- SHA-256 всех ранее существовавших отслеживаемых файлов сравнен
  до и после работы: **ни один файл не изменён**, включая PDF 01–11
  и всю исходную web-презентацию.
