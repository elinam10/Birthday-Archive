# Birthday Archive — prototype

Static animated browser experience based on the video brief. It uses plain HTML, CSS and JavaScript, so it can be published directly with GitHub Pages.

## Run locally

Open `index.html` directly, or serve this directory with any static web server.

## Controls

- Enter: start
- Left / right arrow: change scene
- Space: pause or resume automatic playback
- The left dock and footer controls also provide manual navigation

## Publish with GitHub Pages

Push this folder to a GitHub repository and select the repository root (or move these files to `/docs`) as the Pages source in repository settings.
