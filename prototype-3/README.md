# Prototype 3 — Terminal Archive

Единая консольная (CRT) подача всех 10 кадров брифа: формат посередине не меняется,
фотографии открываются в отдельном ретро-окне поверх кадра.

Статика без зависимостей — работает и с GitHub Pages, и открытием `index.html` напрямую.

## Отличия от прототипов 1 и 2

| | Прототип 3 |
|---|---|
| Стиль | один CRT-терминал на все 10 кадров (заказчик разрешил не переключаться на светлый) |
| Фото | открываются в окне приложения (клик по слоту / Enter) |
| Управление | автоплей как у ролика + ручной шаг, пауза, повтор кадра, индекс сцен |
| Анимации | печать текста, счётчики, прогресс-бары, «тетрис» карточек, метки на карте, LOCKED → UNLOCKED |
| Пауза | 7–10 c тишины между кадром 9 и кадром 10 (как в брифе) |

## Управление

- `START ARCHIVE` — запуск (он же разблокирует звук)
- `←` / `→` — предыдущий / следующий кадр
- `Space` — пауза / продолжить
- `R` — повторить текущий кадр
- `☰ SCENES` — список кадров
- `AUTO` — автопроигрывание, `SPEED` — 1× / 1.5× / 2×
- `ANIM: A / B` — два режима подачи из брифа:
  - **A** — карточка приходит поверх кадра, zoom in, затем встаёт на место
  - **B** — кадр показан целиком, объекты по очереди подсвечиваются для чтения
- `CRT` — развёртка старого монитора вкл/выкл
- Общая кнопка `SOUND ON/OFF` — из `../assets/audio-control.js`

## Звук

Используется звуковая библиотека самого репозитория (`../assets/sounds/`):

| Роль | Файл |
|---|---|
| загрузка / архив | `matrix-monitor.mp3` |
| скан фото (кадр 3) | `scan.mp3` |
| метки на карте | `matrix-materialize.mp3` |
| фон кадров 4–9 | `matrix-clubbed-to-death.mp3` (затихает перед кадром 10) |
| финал | `rick-and-morty-intro.mp3` |

## Правка текста

Весь текст 10 кадров — в `content.js`. Вёрстку трогать не нужно.

## Файлы

- `content.js` — контент всех кадров
- `engine.js` — таймлайн, печать, прогресс-бары, счётчики, окно с фото, звук, салюты
- `scenes.js` — сборка и сценарий каждого из 10 кадров
- `app.js` — загрузка, менеджер сцен, HUD, управление
- `styles.css` — оформление
